# ADR-003: Порты и адаптеры (SOLID, DIP)

## Контекст

Нужно решить, как организовать доступ домена к внешним зависимостям
(хранилище сессий, парсер JSON). Варианты: прямые зависимости на
реализации или через интерфейсы.

## Решение

**Порты и адаптеры.** Домен работает с интерфейсами (`port/`),
реализации — в `infrastructure/`.

## Обоснование

- Домен не знает про Spring, Caffeine, Jackson.
- Легко заменить реализацию (Caffeine → Redis).
- Соответствует принципу инверсии зависимостей (DIP).
- Домен тестируется без Spring.

## Последствия

- Больше файлов (интерфейс + реализация).
- Немного сложнее навигация по проекту.
- Гибкость и тестируемость — того стоят.
