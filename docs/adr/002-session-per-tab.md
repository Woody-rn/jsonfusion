# ADR-002: Одна сессия на вкладку браузера

## Контекст

Пользователь может открыть несколько вкладок. Нужно решить: одна сессия
на браузер или своя на каждую вкладку. Хранить `sessionId` можно в
`localStorage` (общий для вкладок) или `sessionStorage` (свой на вкладку).

## Решение

**Одна сессия на вкладку.** `sessionId` хранится в `sessionStorage`.

## Обоснование

- Нет конфликтов между вкладками — каждая работает со своей сессией.
- Логично: одна вкладка = одна операция мержа.
- Просто реализуется: `sessionStorage` изолирован по вкладке.

## Последствия

- При закрытии вкладки сессия теряется (клиент не может вернуться).
- Сессия на бэке живёт до TTL и потом удаляется.
