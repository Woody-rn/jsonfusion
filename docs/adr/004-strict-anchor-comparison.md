# ADR-004: Сравнение якоря — регистр и пробелы

## Контекст

Якорь — поле, по которому сопоставляются записи. Реальные данные грязные:
`ООО Ромашка` vs `ООО ромашка` vs `ООО Ромашка ` (хвостовой пробел).
Нужно решить, как сравнивать.

## Решение

По умолчанию:
- **без учёта регистра**,
- **trim + collapse пробелов**.

Оба поведения — под галочками в UI (вкл по умолчанию).

## Обоснование

- 99% случаев: `ООО Ромашка` и `ООО ромашка` — одна компания.
- Хвостовые и двойные пробелы — шум.
- Пробелы **внутри** слова значимы (`ООО Ромашка` ≠ `ОООРомашка`).
- Пользователь может отключить нормализацию, если нужна строгость.

## Последствия

- Значение якоря в результат берётся **из F1 как есть** (оригинал).
- Возможны редкие ложные совпадения (`Иван Петров` vs `иван петров`).
- Пользователь контролирует строгость через галочки.
